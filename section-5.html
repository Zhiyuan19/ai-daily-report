智谱 AI 发布首个原生多模态 Coding 基座模型 GLM-5V-Turbo

来源： 科创板日报 | 发布时间：2026-04-02

核心内容： 智谱发布 GLM-5V-Turbo，这是国内首个原生多模态编程基座模型，最大突破在于深度融合视觉与编程能力——能原生处理文本、图片、视频等多模态信息，同时擅长编程、长程规划和操作执行。

该模型让 OpenClaw（智谱个人 AI 助手）具备了真正的视觉能力，能"看懂屏幕上的信息"。目前已通过智谱 MaaS 平台开放 API 接入。模型基于 GLM-5.1 系列扩展，在视觉理解和代码生成的双重能力上达到国产第一梯队。

链接： https://model-platform.zhipuai.cn

阿里 Qwen 3.6-Max 预览版发布：六项编程基准全球第一

来源： 阿里云/IT之家 | 发布时间：2026-04-20

核心内容： 阿里发布 Qwen3.6-Max-Preview，这是 Qwen 系列新一代旗舰模型的早期预览版。核心升级：在 SWE-bench Pro、Terminal-Bench 2.0、SkillsBench、QwenClawBench、QwenWebBench 和 SciCode 六项主要编程基准上取得最高分，世界知识和指令遵循能力也有显著提升。

相比 Qwen3.6-Plus，新模型在智能体编程方面提升显著，即将通过阿里云百炼 API 开放调用。

链接： https://qwen.xyz.cn

字节 Seedance 2.0 API 上线 1080P 原生视频生成

来源： 火山引擎/IT之家 | 发布时间：2026-04-21
