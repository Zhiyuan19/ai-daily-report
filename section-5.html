智谱 AI 发布 GLM-5 底层工程突破：系统吞吐量最高提升 132%，异常率降至万分之一以下

来源： 证券时报 | 发布时间：2026-04-30

核心内容： 智谱 AI 工程团队于 4 月 30 日发布技术博客《Scaling Pain：超大规模 Coding Agent 推理实践》，首次系统披露 GLM-5 在 Coding Agent 调用场景下的底层性能优化成果。在超大规模并发调用下（推断为日均数亿 token 级别），系统吞吐量经底层工程优化后最高提升 132%；系统异常输出率从"万分之十几"的量级下降至"万分之三以下"——异常输出直接影响用户体验和 token 成本消耗，此次降幅意义重大。

更值得关注的是，智谱团队将完整的修复方案通过 Pull Request #22811 提交给了主流开源推理框架 SGLang 社区，而非仅在内部使用。这意味着整个开源生态都将受益于这次优化，是一次难得的开源贡献案例。智谱作为"全球大模型第一股"，在底层工程能力上的公开分享对行业有标杆意义。

链接： https://www.stcn.com/article/detail/3891105.html

腾讯混元 Hy3 Preview 开源：295B 总量、21B 激活参数、256K 上下文，定位快慢思考融合

来源： 网易科技 | 发布时间：2026-04-28

核心内容： 4 月 23 日，腾讯混元发布并开源了重建后的首款语言模型 Hy3 Preview，定位为"快慢思考融合"的混合专家模型（MoE）。总参数量 295B，激活参数 21B，最大支持 256K token 上下文长度。官方表示，Hy3 在复杂推理、指令遵循、代码生成、智能体任务等能力上实现大幅提升，同时大幅降低了单任务推理成本，目标是"让智能用得起"。

腾讯混元同期还发布了 3D 世界模型 2.0，实现 3DGS（3D Gaussian Splatting）与 Mesh 双表征融合生成，与阿里同日在世界模型赛道发力。此外，腾讯云混元系列模型自 3 月中旬以来价格涨幅达 463%，反映市场需求的快速攀升。

链接： https://www.163.com/dy/article/KRP5IC7C05118I96.html

阿里云 Qwen3.6 密集迭代：旗舰预览版 + 27B 开源，稠密架构验证 Agent 编程参数效率

来源： 网易科技 | 发布时间：2026-04-28

核心内容： 阿里云通义千问近期动作密集：先是发布新一代旗舰模型早期预览版 Qwen3.6-Max-Preview，在智能体编程和世界知识等能力上持续迭代；随后正式开源 Qwen3.6-27B，用稠密架构（Dense Architecture）验证了在 Agent 编程场景下的参数效率极限——27B 规模实现了此前 70B+ 参数模型才能达到的编程能力。

根据 Hugging Face 报告，中国大模型过去一年占据全球下载量的 41%，阿里 Qwen 系列衍生模型已超过 11.3 万个，数量和增速均居全球前列。阿里云 CFO 吴泳铭表示，公司目标是五年内云和 AI 外部收入合计超过 1000 亿美元。

链接： https://www.163.com/dy/article/KRP5IC7C05118I96.html

字节跳动豆包月活突破 3 亿，Coze 低代码智能体平台持续领跑

来源： DeepTech 深科技 | 发布时间：2026-04-30

核心内容： 字节跳动的豆包 AI 在 2026 年月活跃用户已突破 3 亿，成为国内用户规模最大的 AI 助手之一。其核心竞争力在于多模态能力与字节系内容生态的深度绑定——覆盖抖音、西瓜视频、今日头条等字节系产品的内容理解与分发。

同时，字节跳动的 Coze（扣子）智能体构建平台持续降低 AI 开发门槛，通过拖拽式组件和自然语言描述，开发者在几分钟内即可构建具备插件能力的智能体。Coze 的定位与 OpenFang 等国际开源工具形成直接竞争，但在国内生态的覆盖度上有明显优势。

《时代》杂志在 2026 年"十大最具影响力 AI 企业"中纳入字节跳动，并指出其 2025 年 AI 基础设施资本支出预算超过 200 亿美元，大部分将用于人工智能算力建设。

链接： https://deepseek.csdn.net/69f32ab954b52172bc70fc60.html
