🇨🇳 五、国内技术圈

1. 🧮 智谱 AI — GLM-5.1 发布，国产大模型再破纪录

  • 来源：智谱 AI 官网 / 微信公众号
  • 发布时间：2026-04-15
  • 链接：https://www.zhipuai.cn
  • 摘要：智谱发布 GLM-5.1，在 MMLU 上达到 92.3%（+2.1pp），首次超越 GPT-4o-mini 基准分数；新增128K Context 原生支持；多模态理解（图像+视频+文档）全面升级。同步开源 GLM-5.1-9B 和 GLM-5.1-32B 权重，Apache 2.0 License。
  • 影响：智谱成为继 Qwen 之后第二个在主流评测中与 GPT-4o-mini 正面竞争的国产开源模型，GLM-5.1-9B 的性价比在国产模型中极具竞争力。

2. ☁️ 阿里云百炼 & Qwen3.5 开源全家桶

  • 来源：阿里云开发者社区
  • 发布时间：2026-04-10~17
  • 摘要：阿里云百炼平台新增 Qwen3.5 全系模型托管，新增"模型评测"功能和"Prompt 市场"；Qwen3.5 开源版本（Qwen3.5-1.8B / 7B / 14B / 72B）在 GitHub 持续活跃，DeepTutor 等项目已将其列为推荐的本地模型选项。Qwen3.6-Plus 百万上下文版同期在 HuggingFace 和 ModelScope 双平台上架。
  • 影响：阿里云百炼正成为国内最活跃的模型分发平台，其 API 定价策略直接影响国内 LLM API 市场格局。

3. 💡 百度文心一言 & Ernie Bot 4 Turbo 发布

  • 来源：百度 AI 官方
  • 发布时间：2026-04-12
  • 链接：https://yiyan.baidu.com
  • 摘要：百度发布 Ernie Bot 4 Turbo，在ERNIE-4-Turbo-128K 上线长上下文 API，支持 128K token 输入和 32K 输出，价格比 GPT-4o 低 60%。同步开源 Ernie-4-Turbo-8K 系列权重。同时开放 Qianfan 调用接口，支持 SiliconFlow / Step Fun / VolcEngine 等国内推理平台接入。
  • 影响：百度通过"低价 + 长上下文"策略争夺企业级市场，Ernie Bot API 已进入 DeepTutor 等开源项目的推荐列表，生态渗透正在加速。

4. 🔊 字节跳动 Coze 和 豆包AI — 新一代多模态 Agent 平台

  • 来源：字节跳动技术博客
  • 发布时间：2026-04-14
  • 摘要：字节跳动发布 Coze 新一代多模态 Agent 编排平台，支持图像 + 视频 + 语音统一输入，支持 Dify / LangFlow 工作流导入。豆包 AI 桌面端新增"AI Tutor 模式"，集成 DeepTutor 协议（见板块洞察）。
  • 影响：字节以"平台 + 流量"优势切入 AI Tutor 赛道，Coze 的低代码 Agent 编排能力降低了国内中小企业接入 AI Agent 的门槛。

5. 🗣️ 讯飞星火认知大模型 — V4.0 发布，语音交互再升级

  • 来源：科大讯飞官方
  • 发布时间：2026-04-18
  • 链接：https://xinghuo.xfyun.cn
  • 摘要：讯飞星火 V4.0 发布，核心升级：全端语音延迟压至 200ms 以内，业内领先；新增"多方言无缝切换"功能，覆盖23种方言；语音合成自然度 MOS 分达 4.8（近乎真人）。同步开源 讯飞听见 语音识别模型（4B），支持流式 ASR。
  • 影响：讯飞在语音 AI 领域的技术壁垒依然稳固，语音模型开源将推动国内语音助手和车载 AI 的又一次升级。
