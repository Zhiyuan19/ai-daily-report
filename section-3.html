OpenAI 发布语音智能 API 更新：长上下文 Agent 利器

来源： OpenAI 官方博客 | 发布时间：2026年5月7日

核心内容： OpenAI 于5月7日发布语音智能 API 的重大更新，核心提升聚焦于 Agent 工作流。主要特性包括：

  • 并行工具调用（Parallel Tool Calls）：模型可同时调用多个工具，并通过"checking your calendar""looking that up now"等语音短语让用户感知正在执行的操作，改善实时交互体验。
  • Preambles（引导语）：开发者可在主响应前插入短句，让 Agent 在工具调用等待期间主动告知用户进展，改善对话节奏感。
  • 更强恢复能力：模型在工具调用失败时不再静默中断，而是以"I’m having trouble with that right now"等自然语言解释并提供替代方案。
  • 上下文窗口从 32K 扩展至 128K：支持更长周期、更多步骤的 Agent 会话，特别适合需要跨多轮收集信息的复杂任务。

这是 OpenAI 5月第二波重大发布（GPT-5.5-Cyber 于5月7日同步推出），展现了其在 Agent 基础设施上的密集投入。

链接： https://openai.com/index/advancing-voice-intelligence-with-new-models-in-the-api/

Anthropic 发布 Claude Security：企业级代码安全扫描全面开放

来源： Anthropic 官方博客 / Releasebot | 发布时间：2026年5月7日

核心内容： Anthropic 宣布 Claude Security（此前称为 Claude Code Security）向所有 Enterprise 客户全面开放。该产品基于 Claude Opus 4.7，在代码漏洞发现和修复任务中准确率显著领先于其他模型。

关键更新包括：定时扫描和定向扫描计划、企业审计系统集成、改进的漏洞分类追踪界面、以及与现有 CI/CD 管线的简易集成——无需 API 集成或自定义 Agent 构建，任何使用 Claude 的组织均可立即启用。

Anthropic 还同步更新了其研究博客"Teaching Claude Why"，探讨模型理解行为原因而非仅理解行为本身的重要性，暗示下一代 Claude 将具备更深的自我建模能力。

链接： https://www.anthropic.com/research/teaching-claude-why

Anthropic Institute 发布：自主 Agent 成为正式研究支柱

来源： Anthropic 官方博客 | 发布时间：2026年5月7日

核心内容： Anthropic Institute（Anthropic 的研究机构）在 Code with Claude 大会上宣布，将自主 AI Agent 新增为与"可解释性""对齐"并列的核心研究支柱。研究方向涵盖：

  • 治理与安全：自主 Agent 的行为边界和外部监督机制
  • 可靠性：Agent 在长时间运行中的决策一致性
  • Agent 间交互：多 Agent 协作的安全协议和信息隔离

这与 Google 同日发布的 Interactions API 重大架构更新（从 outputs 迁移到 steps 数组）形成呼应，标志着全球主要 AI 实验室正在从"对话式 AI"向"行动式 AI"系统性转型。

链接： https://simonwillison.net/2026/May/6/code-w-claude-2026/

OpenAI 推出 GPT-5.5-Cyber：网络安全专用模型开放预览

来源： OpenAI 官方博客 / CNBC | 发布时间：2026年5月7日

核心内容： OpenAI 宣布 GPT-5.5-Cyber 向经过审查的网络安全团队开放有限预览。这是一款针对安全任务优化的 GPT-5.5 变体，在以下场景做了差异化训练：

  • 漏洞识别与分类
  • 补丁验证
  • 恶意软件分析

与通用 GPT-5.5 相比，GPT-5.5-Cyber 在安全相关任务上更宽松（less restrictive），以允许研究人员在高风险场景下充分探索模型能力——这是一个有意的设计权衡，表明 OpenAI 正在探索"安全能力释放"的分级授权模式。

链接： https://openai.com/index/gpt-5-5-cyber/
