Tempus — 边缘AI推理加速框架

一句话描述： AMD Versal AI Edge 专用 GEMM 加速框架，单芯片达成 607 GOPS 吞吐量。

背景与原理： 高性能矩阵运算（GEMM）是所有大模型推理的核心计算单元。传统方案依赖 CUDA/通用 GPU，在边缘端面临功耗与成本双重约束。Tempus 专为 AMD Versal AI Edge 平台设计，通过指令级并行、AIE-ML 核协同调度与内存层级优化，将硬件理论算力完整释放。

核心创新点： - 零门槛移植：无需修改模型权重，直接对接 ONNX/MatMul 接口 - 资源无关架构：16 核配置下即可达 607 GOPS，核数减少性能线性缩放，不存在"核少不能用"问题 - 与竞品对比：相比同类开源 GEMM 框架（多为 200–400 GOPS），Tempus 性能提升 52%–203%

实际意义： 边缘 AI 推理市场（Laptops、汽车座舱、工业终端）正高速增长，但工具链碎片化严重。Tempus 填补了 AMD 边缘平台高性能推理的开源空白，开发者无需等待芯片厂商优化即可获得接近硬件上限的性能。

取得的突破： 607 GOPS / 16 核 | 相比竞品最高提升 203% | GitHub: https://github.com/xxx/tempus

OpenHive — 零配置多智能体执行框架

一句话描述： 零配置、模型无关的多智能体拓扑生成与执行框架，专注长时序复杂业务任务。

背景与原理： 多智能体系统（Multi-Agent）已从研究走向生产，但现有方案（如 LangGraph、CrewAI）仍需大量编排代码，在企业级长时序任务中存在明显瓶颈。OpenHive 提出"拓扑即配置"范式，用户只需声明任务目标，系统自动生成最优智能体协作拓扑。

核心创新点： - 拓扑动态生成：根据任务复杂度自动决定智能体数量与角色分工 - 模型无关：支持 Claude / GPT / Gemini / 开源模型混用 - 无外部依赖：单文件约 200KB，适合嵌入现有应用

实际意义： 企业部署多智能体系统的门槛从"3–4 周开发"压缩到"1 小时配置"，特别适合客服自动化、业务审批、代码审查等长链路场景。

取得的突破： GitHub trending 周增速 top 5 | Apache 2.0 开源许可 | https://github.com/aden-hive/hive

Agent Swarm — 多框架适配的 AI 编码智能体编排框架

一句话描述： 支持 Claude / OpenAI / Pi-Mono 多 provider 统一编排的代码智能体框架。

背景与原理： AI 编码工具正从单模型向多智能体演进，开发者常需同时使用 Claude Code、GPT-Code 和国产方案。Agent Swarm 通过 ProviderAdapter 抽象层，将不同 CLI/SDK 的接入逻辑统一封装，开发者只需调用统一接口即可切换底层 provider。

核心创新点： - ProviderAdapter 抽象：新增 provider 只需实现标准化接口，无需改动核心调度逻辑 - Pi-Mono 首发支持：通过 MCP 协议发现工具，与国产代码智能体生态深度集成 - 会话持久化：支持断点续跑、结果缓存与成本追踪

实际意义： 打破了"换模型 = 重写代码"的企业级痛点，为 AI 编码工具的采购决策提供灵活性，团队可以按项目、按场景选择最优模型而不被框架锁定。

取得的突破： 已支持 3 大 provider | Apache 2.0 | 近期 50+ PR 合并 | https://github.com/desplega-ai/agent-swarm

9router — AI 路由负载均衡器

一句话描述： 聚合多路 AI API 并智能调度，降低 40% 调用成本的开源路由工具。

背景与原理： 随着 AI 模型提供商增多，开发者常同时使用 OpenAI、Anthropic、国内模型等多个 API，缺乏统一调度层导致：① 单渠道速率限制卡脖子；② 无法根据任务类型匹配合适模型；③ 账单碎片化难以优化。9router 作为 API 网关层，实时监控各渠道可用性、延迟与成本，智能路由请求。

核心创新点： - 实时健康检测：自动屏蔽故障渠道，请求自动 fail-over - 成本感知调度：简单任务路由至低成本模型，复杂任务自动升级 - 支持代理/直连混合模式：适配企业内网环境

实际意义： 实测降低 35–45% AI API 账单，同时将可用性从 99% 提升至 99.95%。对日均调用量超百万 Token 的团队，直接 ROI 明显。

取得的突破： GitHub 日增 800+ stars | MIT 开源 | https://github.com/9router/9router

DeepSeek-TUI — 终端深度推理交互工具

一句话描述： 为 DeepSeek 系列模型打造的终端原生交互界面，支持长时间连续推理与上下文复用。

背景与原理： DeepSeek 模型以高性价比和强大推理能力著称，但网页/APP 界面在长时间编码任务中交互效率低。DeepSeek-TUI 提供全键盘操作的终端界面，支持会话分屏、上下文书签、输出导出，特别适合 8 小时+ 连续编码场景。

核心创新点： - 终端原生：无需浏览器，直接在 shell 内完成全流程 - 上下文快照：支持随时保存/恢复长会话状态 - 结构化输出：代码块语法高亮、diff 视图、测试结果直接渲染

实际意义： 为国内开发者提供了 DeepSeek 模型在本地/服务器环境的高效使用路径，减少了模型能力与交互效率之间的落差。

取得的突破： GitHub trending 本周上升最快的中国开源项目之一 | https://github.com/deepseek-ai/tui
