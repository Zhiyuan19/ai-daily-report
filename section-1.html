📌 今日精选

1️⃣ RAD-2：生成器-判别器框架下的强化学习扩展

标签： 强化学习 RL Generator-Discriminator

原理： RAD-2 提出在 Generator-Discriminator（生成器-判别器）框架下扩展强化学习规模。生成器负责产生策略/动作，判别器评估生成质量并提供改进信号，两者通过对抗性训练协同进化，实现比传统 RL 方法更高效的能力扩展。

创新点： - 引入生成器-判别器博弈机制替代传统 reward model - 多任务梯度共享减少样本复杂度 - 可扩展至超大规模模型（100B+ 参数）

实际意义： 为超大规模语言模型的推理能力提升提供了新训练范式，在代码生成、数学推理等任务上相比 GRPO 等基线方法有显著提升。

链接： https://huggingface.co/papers (HuggingFace Daily Paper, 2054👍)

2️⃣ HY-World 2.0：多模态世界模型重建与仿真

标签： 世界模型 3D重建 多模态 仿真

原理： HY-World 2.0 是一个能够重建、生成和仿真 3D 世界的新型多模态世界模型。模型同时处理图像、文本、深度和点云等多种输入，构建环境的统一表征，并支持在虚拟环境中进行机器人操作规划和交互式仿真。

创新点： - 统一的多模态 3D 表征学习框架 - 可泛化的跨场景物理仿真能力 - 支持机器人操作的可微分仿真环境

实际意义： 对自动驾驶仿真、机器人训练和具身智能研究具有重要推动意义，可大幅降低真实环境训练成本。

链接： https://huggingface.co/papers (HuggingFace Daily Paper, 1020👍)

3️⃣ DR³-Eval：深度研究评估的标准化基准

标签： 评估基准 深度研究 Agent

原理： DR³-Eval 提出针对深度研究任务（Deep Research）的系统性评估框架，覆盖信息检索、多步推理、文档综合等核心能力，设计了可重现的自动化评测流程和多维度打分标准。

创新点： - 首个针对深度研究场景的标准化评估基准 - 细粒度能力拆解（检索→推理→综合→验证） - 支持模型间横向对比和纵向迭代追踪

实际意义： 为 AI 研究助手和 Agent 系统的能力评估提供了可信标尺，帮助学术界和工业界客观衡量技术进展。

链接： https://huggingface.co/papers (HuggingFace Daily Paper, 182👍)

4️⃣ SparseBalance：动态稀疏注意力的长上下文负载均衡

标签： 长上下文 注意力机制 Transformer优化

原理： SparseBalance 通过动态稀疏注意力机制，在长上下文训练中实现各层之间的负载均衡。传统稀疏注意力存在热点集中问题， SparseBalance 根据 Query-Key 交互频率动态调整稀疏模式，避免算力瓶颈。

创新点： - 跨层动态稀疏模式自适应 - 消除传统稀疏注意力的负载倾斜问题 - 与标准 FlashAttention 接口兼容

实际意义： 对处理百万级 Token 上下文的大模型推理至关重要，可显著降低长文本场景下的显存占用和计算延迟。

链接： https://arxiv.org/abs/2604.13847

5️⃣ Golden Handcuffs：让 AI Agent 更安全的激励机制设计

标签： AI安全 Agent 对齐

原理： 论文从激励机制角度研究如何约束 AI Agent 行为，提出"金手铐"（Golden Handcuffs）概念：通过精心设计的奖励结构，使 AI Agent 在追求目标时内生地规避有害行为，而非事后依赖外部规则限制。

创新点： - 从激励设计角度而非规则约束角度解决 AI 安全问题 - 证明特定奖励结构可内生安全行为 - 为 Agent 安全性提供了新的理论分析框架

实际意义： 对构建可靠、可控的 AI Agent 系统具有重要参考价值，是 AI 安全领域从"外部限制"向"内生约束"转变的标志性工作。

链接： https://arxiv.org/abs/2604.13609

6️⃣ BOAT：抗体设计的多目标贝叶斯优化

标签： 生物医药 贝叶斯优化 AI制药

原理： BOAT（Bayesian Optimization for Antibody Design）将多目标贝叶斯优化引入抗体设计，模型同时优化抗体的亲和力、稳定性、免疫原性等多个目标，利用不确定性量化指导实验设计，在少量实验迭代中找到最优候选。

创新点： - 首个专为抗体设计定制的多目标贝叶斯优化框架 - 不确定性驱动的探索-利用平衡策略 - 支持先导化合物迭代优化

实际意义： 可加速抗体药物发现流程，将传统需要数年筛选的抗体优化周期大幅缩短，对 AI 制药领域具有直接应用价值。

链接： https://arxiv.org/abs/2604.13980

7️⃣ Helios：真正的实时长视频生成模型

标签： 视频生成 Diffusion 实时推理

原理： Helios 是字节跳动发布的实时长视频生成模型，能够在保持高画面质量的同时实现实时推理。模型采用新型 Diffusion 架构，通过时间轴注意力机制和分层生成策略，支持分钟级连贯视频生成。

创新点： - 端到端实时推理管线 - 长时序一致性建模（分钟级） - 支持细粒度动作控制

实际意义： 对影视制作、游戏引擎和虚拟数字人等领域有直接商业价值，是视频生成从"离线渲染"向"实时生成"迈进的重要里程碑。

链接： https://huggingface.co/papers (HuggingFace Daily Paper, 1.7k👍)
