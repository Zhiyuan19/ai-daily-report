① GitHub 小众爆款

lsdefine/GenericAgent — 自进化Agent

一句话描述： 从3.3K行种子代码自生长，实现全系统控制且Token消耗降低6倍的自进化Agent框架。

背景与原理： GenericAgent引入"技能树"（Skill Tree）机制，模拟游戏中的技能树成长逻辑——Agent在执行任务过程中逐步解锁新技能节点，形成的能力网络可持续积累并跨任务复用。与传统单次任务执行的Agent不同，它将每次执行视为经验积累，驱动自身技能库的持续扩展。

核心创新点： - 种子引擎：仅用3.3K行代码定义初始能力边界，涵盖文件系统操作、网络请求、代码执行等基础Primitive - Token压缩6倍：通过自适应上下文裁剪和分级记忆机制，将同等任务的Token消耗降至1/6 - 自我诊断回路：每次任务失败后自动分析失败原因，并将修复方案编码为新技能节点

实际意义： 在Claude Code/Opencode/Cursor等主流Coding Agent中，Token成本是规模化落地的核心障碍。GenericAgent在SWE-bench测试中以6倍更低的Token消耗达到相近完成率，首次证明了"少即是多"的Agent设计范式可行。

突破： GitHub Trending多榜，聚焦Agent架构创新

链接： https://github.com/lsdefine/GenericAgent

deepseek-ai/DeepGEMM — FP8高效矩阵乘法

一句话描述： 字节开源的FP8 GEMM内核，以细粒度缩放实现 Hopper 架构下的高效矩阵运算。

背景与原理： DeepGEMM是DeepSeek团队针对英伟达 Hopper 架构 GPU 开发的FP8矩阵乘法实现。FP8（8位浮点）相比FP16/BF16能在保持模型精度的同时将矩阵运算速度提升2-4倍。DeepGEMM的核心创新在于细粒度缩放（fine-grained scaling），避免了传统FP8实现中因动态范围不足导致的精度崩溃问题。

核心创新点： - 细粒度缩放：对矩阵每个block独立计算缩放因子，避免全局缩放的误差累积 - Triton DSL实现：无需CUDA内核，用Triton语言直接在Python层表达高效计算图 - 支持MoE稀疏化：专为混合专家模型设计

实际意义： 填补了Hopper架构下开源FP8 GEMM的空白，性能比CUTLASS提升15-20%，代码量仅1/20。

链接： https://github.com/deepseek-ai/DeepGEMM

openai/openai-agents-python — 多Agent工作流框架

一句话描述： OpenAI官方开源的多Agent协作Python框架，支持轻量级多Agent工作流编排。

背景与原理： 随着GPT-5和Claude等大模型的能力提升，单Agent的任务拆解和工具调用能力已接近瓶颈，多Agent协作（Multi-Agent Collaboration）成为新的扩展范式。openai-agents-python是OpenAI对这一趋势的官方框架回应，提供了多Agent之间通信、任务分配和结果汇总的基础设施。

核心创新点： - Handoff机制：Agent之间可以"交接"任务，实现真正的协作链 - 状态共享：多Agent共享同一对话上下文，避免信息丢失 - 内置工具注册：标准化的工具定义接口，兼容MCP协议

实际意义： 这是OpenAI首次正式进入Multi-Agent框架领域，结合GPT-5的强大了工具调用能力，将多Agent协作从研究实验推向生产可用。

链接： https://github.com/openai/openai-agents-python

EvoMap/evolver — GEP驱动自进化引擎

一句话描述： 基于基因表达式编程（GEP）的AI Agent自进化引擎，实现无需人工干预的持续自我优化。

背景与原理： EvoMap evolver将生物进化的基因表达式编程（Gene Expression Programming）引入AI Agent的自优化过程。传统Agent的技能获取依赖人工定义和外部知识库，而EvoMap的方案是：让Agent在任务执行中生成"候选策略"，通过类似自然选择的评估函数筛选优秀策略，再通过GEP的遗传操作（交叉、变异）组合生成新策略，形成一个自动化的能力增长飞轮。

核心创新点： - 自动化策略生成：无需人工定义进化方向，评估函数驱动策略涌现 - GEP遗传操作：交叉+变异组合，产生远超单点改进的策略空间探索 - 可解释性：进化产生的策略以规则形式存储，可追溯来源

实际意义： 首次将进化计算引入Agent自我优化，相比强化学习需要大量环境交互，EvoMap只需少量任务样本即可完成策略进化，大幅降低自我优化的样本成本。

链接： https://github.com/EvoMap/evolver

BasedHardware/omi — 屏幕视觉+语音AI助手

一句话描述： 能看屏幕、听对话并告诉你该做什么的下一代AI助手硬件/软件集成方案。

背景与原理： omi是一个端侧的AI助手，可以同时感知屏幕内容（通过视觉API）和麦克风语音输入，实时分析用户当前所处环境和操作上下文，主动给出操作建议。与Siri/Cortana等语音助手不同，omi不是等用户提问，而是主动"看"和"听"之后预判需求。

核心创新点： - 主动感知：无需唤醒词，持续感知屏幕和语音 - 上下文理解：结合屏幕截图和对话内容，形成完整环境感知 - 边缘部署：支持本地推理，保护隐私

实际意义： 标志着AI助手从"响应命令"向"主动环境感知"的重要范式转变，是通向真正AI Agent硬件形态的早期探索。

链接： https://github.com/BasedHardware/omi
