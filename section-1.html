📦 一、GitHub 小众爆款（总星 < 50k）

增速快、小众但实力硬的开源项目，挖掘标准：近7天有重大版本发布或高速增长，<50k stars

1. 🔍 OpenMythos — Claude Mythos 开源复现

  • 链接：https://github.com/KyeGo/OpenMythos
  • Stars：< 5k ⭐（推测，尚未大规模传播）
  • 分类：LLM 复现 / 推理研究
  • 亮点：Anthropic 从未发表 Claude Mythos 技术论文，Kye Go 团队通过逆向工程和社区协作在 GitHub 发起 OpenMythos 项目，尝试从公开信息重建其推理与角色一致性机制。项目采用开放贡献模式，吸引大量 AI 研究者参与，被视为开源社区对闭源模型"透明化"诉求的标志性事件。
  • 为何值得关注：2026 年开源复现闭系模型成风，继 OpenReasoner、OpenClaude 之后，OpenMythos 代表了"可解释 AI"社区的新一波浪潮。

2. 🎭 open-multi-agent — 多代理编排框架

  • 链接：https://github.com/JackChen-me/open-multi-agent
  • Stars：5.5k ⭐
  • 分类：多代理框架
  • 亮点：2026-04-01 正式发布（MIT License），支持 Anthropic / OpenAI / Grok / Gemini / MiniMax / DeepSeek / GitHub Copilot 全家桶适配，内置 AgentPool + TaskQueue + MessageBus 架构，提供 oma CLI 工具，可同时在 Shell 和 CI 环境中运行。verified 模型列表已覆盖 Ollama / vLLM / LM Studio / llama.cpp 全家桶。
  • 为何值得关注：多代理框架中少有的"零配置、多后端"选手，Node.js 生态开发者友好，5.5k 星增速在同类型中属顶级。

3. 🏫 DeepTutor — Agent 原生个性化学习助手

  • 链接：https://github.com/HKUDS/DeepTutor
  • Stars：< 5k ⭐（高速增长中）
  • 分类：AI Tutor / 教育 AI
  • 亮点：港大 HKUDS 实验室出品，v1.0.0（2026-04-04）上线至今保持高强度迭代（已有 v1.1.0），架构完全 Agent-Native，内置 200k 行重构代码，支持 Tools + Capabilities 插件模型、TutorBot / Co-Writer / Guided Learning 等多模式，Embedding Provider Registry 支持 Qwen / vLLM / LM Studio / llama.cpp，可对接 Qianfan（百度文心）、SiliconFlow、Step Fun、VolcEngine、Zhipu AI（GLM）等国内模型。中文 i18n 完善。
  • 为何值得关注：教育 AI 场景中极少数真正 Agent-Native 的开源方案，中文支持优秀，适合二次开发或接国内模型。

4. 📄 OmniParser — 文档结构化提取

  • 链接：https://github.com/microsoft/OmniParser
  • Stars：< 10k ⭐
  • 分类：文档解析 / RAG
  • 亮点：微软开源的文档解析工具，支持 PDF / PowerPoint / Word / Excel / 图片 / 音频 / HTML → Markdown 转换，内置 OCR + 转录能力，MIT License，可本地 T4 GPU 部署，输出结构化数据直接喂给 GenAI 应用。
  • 为何值得关注：RAG 工作流中"文档解析"是公认痛点，OmniParser 填补了微软官方在开源文档解析领域的空白，性能对标商业方案但完全免费。

5. ⚡ DocETL — Agentic ETL 系统

  • 链接：https://github.com/UCBerkeley/DocETL
  • Stars：< 5k ⭐
  • 分类：数据处理 / ETL / RAG
  • 亮点：UC Berkeley 开源的 LLM-Powered ETL 系统，专攻复杂文档处理流水线，支持 Query Rewriting 和 Evaluation，在非结构化数据分析任务上比基线方案准确率高出 80%，MIT License。
  • 为何值得关注：数据工程师视角的 RAG 增强方案，解决"文档进来、脏数据出去"的核心痛点，在企业级知识库场景有直接价值。

6. 🐂 OpenClaw HiClaw — 多代理协作操作系统

  • 链接：https://github.com/agentscope-ai/HiClaw
  • Stars：4.1k ⭐
  • 分类：多代理 / 协作 AI
  • 亮点：HiClaw 是基于 OpenClaw 构建的协作多代理操作系统，通过 Matrix 协议实现 Agent + Human 实时协作，支持 Higress AI Gateway / Tuwunel (Matrix) / MinIO / Element Web 全栈开源部署，v1.0.9（2026-04-02）最新，Apache-2.0 License。GitHub 提交记录显示 Claude Opus 4.6（1M context）参与代码协作。
  • 为何值得关注：首个将"人在回路"做到 K8s-Native 级别的开源多代理系统，471 forks 说明社区正在积极基于其二次开发。
