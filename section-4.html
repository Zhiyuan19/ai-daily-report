④ 开源工具 & 模型更新

新开源工具、框架、模型（含国际+国内开源）

LittleLamb Model Family — 三个超小模型的Agent部署全家桶

超紧凑开源模型三件套：边缘/移动/工具调用全覆盖

背景与原理： 4月28日，AI模型压缩领域的领导者 Multiverse Computing 在 Hugging Face 发布了 LittleLamb 开源模型家族，包含三款基于 Qwen3-0.6B 蒸馏而来的超紧凑模型：LittleLamb 0.3B（通用版）、LittleLamb 0.3B Tool-Calling（工具调用优化版）和 LittleLamb 0.3B Mobile（移动端优化版）。

这三款模型使用了 Multiverse 自研的 CompactifAI 压缩技术，将 Qwen3-0.6B 的参数量进一步压缩约 50%，同时保持可用的任务性能。Tool-Calling 版本专门针对 Function Calling 和 ReAct 范式进行了激活模式优化，在 API 调用类任务中的准确率接近参数量大其 5 倍的模型。Mobile 版本则侧重于在手机芯片上的能效优化，可在 iPhone 15 Pro 等设备上流畅运行。

核心创新点： 超低参数（0.3B）配合蒸馏优化，实现了真正可以在边缘设备和离线环境中运行的 Agent 能力。传统观念认为只有 7B 以上模型才具备可靠的工具调用能力，LittleLamb 通过精细的激活模式工程打破了这一认知边界。

实际意义： 对于需要在移动端或物联网设备上部署本地 AI 能力的开发者，LittleLamb 提供了三个开箱即用的选项。特别是 Tool-Calling 版本，可以作为端侧 Agent 的"决策引擎"，在本地完成意图分类和工具选择，仅在必要时调用云端 API，从根本上解决数据隐私和离线可用性问题。

星数/增长： 今日发布，首批上线 Hugging Face 即获得社区高度关注

链接： https://huggingface.co/MultiverseComputing/LittleLamb-0.3B

Poolside Laguna XS.2 — 美国初创开源33B MoE编程模型

Apache 2.0许可：本地Agent编程的强力选择

背景与原理： Poolside 是一家美国 AI 初创公司，4月发布并开源了 Laguna XS.2，这是一款 330亿参数（激活 30亿）的混合专家模型（MoE），基于 Apache 2.0 许可证开源，可免费商用。该模型专门针对"本地 Agent 编程"场景优化，支持在单 GPU 甚至部分高端笔记本 GPU 上运行完整推理。

Poolside 强调 Laguna XS.2 并非基于阿里巴巴 Qwen 系列微调的产物，而是从零开始训练，这在当前美国 AI 创业圈中较为罕见，体现了 Poolside 独立的技术路线和算力投入。

核心创新点： 33B 总参数、3B 激活参数的稀疏 MoE 架构，结合 Apache 2.0 许可，使其成为目前市面上最具性价比的"可商用本地编程模型"。开发者在 Mac M3 Pro（64GB）或配备 RTX 4090 的 PC 上即可运行 Laguna XS.2，获得接近 GPT-4 水平的代码补全和修改建议能力。

实际意义： Laguna XS.2 的开源填补了"Apache 2.0 许可 + 本地可运行 + 编程专精"三重约束下的市场空白。相较于 Llama 3（需要较大显存）和 Code Llama（许可受限），Laguna XS.2 为需要私有化部署和定制微调的企业提供了清晰的选项。

链接： https://huggingface.co/Poolside/laguna-xs.2

Qwen3.5-A3B — 阿里270亿参数稠密编程旗舰

小参数大能量：稠密架构挑战MoE编程能力边界

背景与原理： Qwen3.5-A3B 是阿里云通义千问团队于4月中旬开源的 270亿参数稠密多模态模型（Apache 2.0 许可），代表了"小参数、强性能"路线的最新成果。虽然是稠密架构而非 MoE，但其通过大规模高质量预训练数据和针对性后训练，在 SWE-bench Verified（真实软件工程任务）等权威编程基准上表现出色，达到了通常只有千亿参数模型才能达到的水准。

核心创新点： 阿里团队此次强调 Qwen3.5-A3B 的核心差异化在于"实际编程任务中的可用性"，而非刷榜分数。项目开源后即在魔搭社区（ModelScope）上引发了开发者的大规模关注和微调热潮。

实际意义： Qwen3.5-A3B 为中小型团队提供了一个"零许可成本 + 高编程能力 + 适中算力需求"的模型选择，特别适合作为内部代码助手或垂直领域编程应用的基础模型。

链接： https://huggingface.co/Qwen/Qwen3.5-A3B
