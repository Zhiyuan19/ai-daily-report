新兴开源工具、框架与模型发布（国际+国内开源）

讯飞星火 X2-Flash — 国产算力 MoE 大模型

一句话描述：科大讯飞发布基于华为昇腾 910B 集群训练的 30B MoE 模型，支持 256K 上下文，Token 消耗仅为主流大尺寸模型的三分之一。

背景与原理： 讯飞星火 X2-Flash 是科大讯飞在国产算力生态下的最新旗舰模型，采用当前主流的 MoE（混合专家）架构，总参数量 30B，最大支持 256K 超长上下文。模型完全基于华为昇腾 910B 集群从零训练完成，是国产软硬件协同能力的标志性成果。技术亮点在于率先在国产芯片上实现了 DSA（稀疏注意力机制）与 MTP（多 Token 预测）的联合优化，结合亲和国产芯片的算子和分布式训练策略，将训练效率从 A800 集群的 20% 提升至 90%，解决了长上下文在国产算力平台训练效率低的核心痛点。在智能体强化学习场景，采样推理效率提升 2 倍以上，有效缓解了 910B 上长交互场景采样效率过低影响 RL 训练的问题。

核心创新点： - 256K 超长上下文 + DSA + MTP 三合一国产方案 - Token 消耗为同效果主流模型的 1/3（实测深度研究报告、Skill 管理与调用等任务） - 智能体能力比肩万亿参数模型效果 - 全面兼容 OpenClaw、Claude Code 等国际主流 Agent 框架

实际意义： 星火 X2-Flash 的发布标志着国产大模型在 Agent 能力上首次实现与业界前沿的全面对齐，同时将使用成本压缩至三分之一，为国内开发者提供了真正可用、高性能、低成本的国产 Agent 方案。

链接： https://finance.sina.com.cn/tech/digi/2026-04-29/doc-inhwczph6763572.shtml

LPM 1.0 — 米哈游创始人蔡浩宇团队发布视频角色表演生成模型

一句话描述：Anuttacon（蔡浩宇创立）发布 170 亿参数视频角色表演生成模型 LPM 1.0，解决视频角色生成中表现力、实时性与长时稳定性不可兼得的"不可能三角"。

背景与原理： LPM 1.0（Large Performance Model）由米哈游创始人蔡浩宇成立的 AI 公司 Anuttacon 于 2026 年 4 月发布，采用 170 亿参数的扩散 Transformer 架构，Transformer 作为主干网络处理时序与空间信息。核心创新是集成了"因果式流生成器"，实现低延迟、可持续、无限长度的实时交互能力。项目团队还构建了以人为中心的多模态数据集，融入表演理解与身份感知参考信息，提升角色在视频中的真实性和跨时序一致性。

核心创新点： - 170B 扩散 Transformer + 因果式流生成器，解决视频角色生成"不可能三角" - 支持自定义角色生成 + 自由对话，虚拟角色具备五官、手部、身体动作及微表情 - 可与 ChatGPT、豆包等 A2A（音频到音频）模型组合生成角色视频 - 应用场景：对话式 AI Agent、交互式 NPC、虚拟主播、教育个性化辅导

实际意义： LPM 1.0 是 2026 年视频生成模型领域的重要突破，其"角色一致性 + 实时交互"的组合能力为游戏 NPC、虚拟陪伴和专业内容创作提供了新的技术路径。项目同时在 arXiv 发布技术论文。

链接： https://baike.baidu.com/item/LPM%201.0/67605789

智象未来 HiDream-O1-Image — 原生全模态世界模型

一句话描述：智象未来发布全球首个 UiT 架构的原生全模态世界模型，实现图像、视频、音频、文本、激光雷达等多模态的原生统一建模。

背景与原理： 2026年4月，智象未来发布了新一代原生全模态世界模型架构及图像大模型 HiDream-O1-Image，采用全球首创的 UiT（Universal Image Transformer）架构。该模型标志着公司从视觉生成的多模态大模型正式迈向原生全模态世界模型的技术路线。其核心理念是：真正的世界模型必须能任意输入、任意输出，与物理世界完全打通——单一或有限模态无法完整描述全模态物理世界。技术路径上，UiT 架构在统一表示空间内原生处理所有模态数据，无需针对每个模态设计独立的编码-解码结构，从而在模态融合效率和泛化能力上实现了质的飞跃。

核心创新点： - 全球首创 UiT 架构，原生统一建模所有模态 - 视频精度达毫米级，满足具身智能训练监控与标注要求 - 2026年4月同时上线全球首个专业级 AI 影视创作协作智能体"帧赞"（奇幻悬疑短剧《秦岭青铜诡事录》12小时登顶腾讯视频竖屏热播榜） - 已与百图生科（BioMap）共建微观世界模型用于生物医药

实际意义： 智象未来的全模态路线代表了对"什么是世界模型"这一根本问题的独特回答。在具身智能、游戏引擎、数字孪生等领域均展现出实际商业价值，为行业提供了一条区别于李飞飞 World Labs 和杨立昆自驾具身智能的第三条世界模型技术路径。
