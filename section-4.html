④ 开源工具 & 模型更新

Avenir-Web — 无需训练的开源 Web Agent，成功率 53.7% 逼近 OpenAI Operator

一句话描述：UCL、普林斯顿、爱丁堡大学联合团队推出，无需任何额外训练即可让多模态模型像人类一样操作网页，在 ComplexWebTasks 基准上刷新纪录。

背景与原理： Avenir-Web 解决的是 Web Agent 在复杂网页结构（iframe、多步骤表单、动态加载内容）上操作成功率低的问题。传统方法依赖额外训练或微调，成本高且泛化能力差。Avenir-Web 的核心思路是"让模型更好地理解网页结构"而非"让模型记住更多操作模式"。它通过解析 DOM 树识别交互元素的几何和语义关系，而不是依赖 ID 或 XPath 等脆弱的定位方式。另外，它引入了"操作历史注意力机制"——让模型在执行下一步操作时能参考前面的操作序列，减少重复错误。

核心创新点： - 零训练成本：直接使用现有多模态模型（如 GPT-4V、Gemini 等），无需微调或 RL 训练 - 复杂 iframe 处理：能正确识别嵌套在多层 iframe 中的可交互元素，这是此前方法的主要失败点 - 操作历史建模：通过注意力机制建模前 N 步操作，防止模型在多步任务中"失忆" - 基准测试领先：成功率 53.7%，距 OpenAI Operator 的 58.3% 不到 5 个百分点，是开源方案中差距最小的

实际意义： Avenir-Web 的价值在于降低了 Web 自动化 AI 的门槛。企业可以直接将现有多模态模型接入 Avenir-Web，无需训练数据或微调基础设施，即可实现"AI 操作网页"的生产级应用。对于需要构建 RPA（机器人流程自动化）替代方案的团队，这是一条低成本的进路。

链接： https://github.com/avenir-web/avenir-web

MiniCPM-o 4.5 — 面壁智能开源全双工全模态模型，12GB 显存即可本地部署

一句话描述：面壁智能联合清华 OpenBMB 开源全双工全模态交互模型 MiniCPM-o 4.5，首次将"人机并行对话"和"环境主动感知"带入端侧 AI，9B 参数兼顾性能与效率。

背景与原理： MiniCPM-o 4.5 基于面壁智能自研的 Omni-Flow 流式全模态框架。传统大模型普遍采用半双工交互——用户说完 AI 才能回复，AI 回复时无法感知环境变化。MiniCPM-o 4.5 通过全双工流式架构实现"边听边说、边看边做"：音频、视频、文本三个模态同时进入模型，模型实时输出多模态响应而无需等待完整输入完成。架构设计上采用 Cross-modal Attention 替代传统的模态融合层，减少了多模态信息相互干扰的问题。

核心创新点： - 全双工交互：用户和 AI 可以同时说话/响应，AI 能实时感知环境变化并主动响应，而非等待用户指令 - 仅 9B 参数：在端侧硬件（12GB 显存）上即可运行，性能接近部分 70B+ 参数模型 - 全模态覆盖：支持音频（语音对话）、视频（摄像头输入）、文本三模态实时融合 - 开源完整：技术报告、权重、推理代码全部公开，支持私有部署

实际意义： MiniCPM-o 4.5 解决的是"端侧 AI 无法实现真正实时交互"的问题。过去的端侧模型要么只支持单模态（语音或文字），要么需要整句输入完成后才能处理，交互延迟高。Avenir-Web 的突破让端侧 AI 第一次具备接近手机语音助手（如 Siri）的实时感知能力，同时完全免费且可离线运行。对于隐私敏感场景（如车载、耳机端侧 AI），这是重要的技术进展。

链接： https://github.com/OpenBMB/MiniCPM-o

SenseNova U1 — 商汤开源 8B 图文生成模型，复刻 GPT-Image-2 能力

一句话描述：商汤科技开源 8B 参数图文生成模型 SenseNova U1，在中文海报、直播画面、社交截图等场景下达到与 GPT-Image-2 相近的生成质量，完全免费可本地部署。

背景与原理： SenseNova U1 瞄准的是"GPT-Image-2 能力本地化"这一需求。GPT-Image-2 在云端效果惊艳，但免费用户每日有配额限制，且无法私有部署。商汤团队通过知识蒸馏将 GPT-Image-2 的核心能力迁移到一个 8B 参数的开放模型上，并在中文场景做了专项优化（如中文字体渲染、中文构图习惯）。模型架构基于扩散模型（Diffusion Model）+ Cross-attention 的图文对齐机制，支持多轮对话式生成（上一轮生成结果影响下一轮的条件输入）。

核心创新点： - 8B 参数本地部署：消费级 GPU（如 RTX 4090）即可运行，无需云端 API - 中文场景专项优化：中文字形、版式、配色均有专项训练，中文海报生成质量显著优于同类开源模型 - 多轮对话生成：支持"先生成背景 → 再添加文字 → 再调整风格"的迭代式创作流程 - 开源免费：Apache 2.0 许可证，商用零成本

实际意义： SenseNova U1 的出现让"AI 图像生成"的能力从云端付费产品下沉到了任何开发者都可以免费获取的资源。对于电商内容生产团队、社交媒体运营者、个人设计师，这提供了一个零成本的自动化生产工具。它的中文优化让国内用户的生成质量首次可以与英文场景的国际模型相媲美。

链接： https://github.com/SenseNova-U1/SenseNova-U1
