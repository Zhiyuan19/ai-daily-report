DeepSeek V4 / V4-Pro / V4-Flash — 刷新开源模型性价比纪录

一句话描述： DeepSeek V4以1.6万亿参数（Pro版）刷新开源模型规模纪录，同时以$0.14/百万输入Token的价格成为成本最低的前沿级开源模型。

深度解析： DeepSeek于4月24日发布V4系列，推出V4-Pro（1.6万亿参数）和V4-Flash（2840亿参数）两个版本。这是全球参数规模最大的开源模型之一，也是DeepSeek在R1之后最受期待的产品。

核心技术创新： - Hybrid Attention Architecture（混合注意力架构）： 改进长对话中的查询历史记忆能力，解决标准Transformer在超长上下文中的信息遗忘问题 - 100万Token上下文窗口： 整本代码库或长文档可作为单次Prompt输入，支持跨文件代码理解和生成 - 极致性价比： V4-Flash定价$0.14/$0.28（输入/输出每百万Token），比GPT-5.4 Nano、Gemini 3.1 Flash更低，是目前最具成本竞争力的前沿级开源模型

开源生态影响： DeepSeek V4针对Anthropic Claude Code和OpenClaw等主流Agent工具进行了专门优化，这意味着开源社区可以以极低成本部署接近前沿能力的智能体后端。对企业用户而言，V4在私有部署场景中的成本优势尤为突出。

链接： https://huggingface.co/deepseek-ai/deepseek-v4

Google发布Gemini CLI — 首个Apache 2.0许可的官方终端Agent

一句话描述： Google发布Gemini CLI，将Gemini的能力带入终端，支持开源开发者构建本地AI工作流。

深度解析： Gemini CLI是Google官方发布的开源终端Agent框架，以Apache 2.0许可证发布，这意味着任何人均可自由使用、修改和商业化。作为与闭源Gemini API互补的产品，CLI版本面向需要本地运行、数据隐私敏感或希望深度定制的开发者。

核心能力： - 多步骤任务自动化：理解自然语言指令，在终端中执行复杂的多步骤操作 - 文件操作与代码生成：直接读写文件系统、运行命令、编写脚本 - 与Git工作流集成：支持代码审查、PR描述生成、commit总结等开发日常任务 - 开源可审查：相比闭源竞品，开发者可完整审计Agent决策逻辑

意义： Gemini CLI的发布标志着Google正式进入开源Agent工具市场，与OpenClaw、CrewAI等形成直接竞争。Apache 2.0许可的姿态表明Google愿意将Gemini的核心能力以不受限制的方式交给社区。

链接： https://github.com/google-gemini/gemini-cli

微软发布Agent Framework v1.0 — 统一AutoGen/Semantic Kernel的企业级Agent平台

一句话描述： 微软正式发布Agent Framework v1.0，整合AutoGen和Semantic Kernel，统一图工作流、A2A协议和MCP支持。

深度解析： 2026年4月2日，微软正式发布Agent Framework v1.0，标志着微软AI Agent战略完成了从分散到统一的收敛。该框架整合了此前独立发展的AutoGen（多Agent对话编排）和Semantic Kernel（企业级AI编排）两条技术路线。

v1.0核心特性： - 图工作流引擎： 支持复杂的多分支、循环和条件判断工作流，适合企业级复杂业务流程 - A2A协议（Agent to Agent）： 标准化不同Agent之间的通信协议，打破厂商锁定 - MCP支持（Model Context Protocol）： 统一上下文管理，支持跨会话的长期记忆 - 检查点与恢复： 支持长时任务的断点续跑，企业关键业务流程不中断 - Python和.NET双语言支持： 覆盖企业主流技术栈

意义： AutoGen本身已宣布进入维护模式，不再开发新功能。微软Agent Framework正在成为微软企业客户的唯一官方选择，其与Azure AI、Copilot的深度集成是其他框架无法复制的护城河。

链接： https://github.com/microsoft/Agent-Framework-Samples
