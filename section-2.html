2.1 Anthropic：「金融服务的 Agent」深度解读

来源：Anthropic 官方博客（2026年5月5日）

Anthropic 发布了「Agents for Financial Services」专项方案，核心要点： - Claude Enterprise Agent 可深度集成银行、投行、风控工作流，执行多步骤复杂任务 - 强调 AI Agent 在金融场景中的责任边界与可审计性，提供完整的决策溯源机制 - 支持与彭博、路透等金融数据 API 的原生集成 - 已与多家 Top 10 国际银行进入 PoC 阶段

意义：Anthropic 正从"通用对话 AI"转向"行业深度 Agent"垂直化落地，金融是目前商业化最成熟的场景。

2.2 DeepMind：Decoupled DiLoCo 论文发布

来源：Google DeepMind 官方 Blog

DeepMind 发布 Decoupled DiLoCo（分布式低通信优化算法变体），核心创新： - 传统 DiLoCo 在多节点并行训练时，节点间通信开销是主要瓶颈 - Decoupled 版本通过梯度压缩 + 异步聚合，将通信频率降低 10 倍 - 已在 Gemma 3n 训练中验证，1T 参数模型跨 128 节点训练效率提升 40% - 论文同步公开，GitHub 有参考实现

意义：分布式训练算法的突破直接决定了下一代超大模型的生产成本，是基础架构层的关键进展。

2.3 Mistral AI：Medium 3.5 发布（4月29日）

来源：Mistral AI 官方 Blog

Mistral 发布 Medium 3.5，定位中端商业应用市场： - 支持 128K 上下文，专注于长文档理解与代码生成 - 推出企业级微调平台，5 分钟即可微调专属垂直模型 - API 定价大幅下调（较 GPT-4o 低 60%），主打性价比 - 发布即支持 MCP（Model Context Protocol）生态

意义：Mistral 正在用"开源旗舰 + 商业中端"的组合拳抢占企业市场，价格战已开启。
