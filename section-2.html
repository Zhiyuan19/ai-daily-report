扩展的工具包：为什么你的脚手架正在融入模型

来源： BestBlogs.dev | 评分：91 | 发布时间：2026年5月8日 20:21 GMT

核心观点： Anthropic 研究产品经理 Lucas 在 Code with Claude 大会上指出，开发者为提高 LLM 可靠性而构建的复杂脚手架（如工具路由器和重试循环）正被模型原生 API 吸收——开发者应停止弥补模型不足，转向将模型连接到独特专有数据。

深度摘要： 这场演讲揭示了大模型能力演进的一个重要临界点：过去需要大量工程努力来实现的能力——工具自主选择、百万 token 上下文、托管代码沙盒、高分辨率屏幕理解——正在直接成为模型 API 的原生功能。

Lucas 将这种现象称为"扩展的工具包"（Expanding Toolkit），并从四个维度展开：1）工具使用：模型现在可以自主从大量工具中做选择并从错误中恢复，手动路由器反而会让效果变差；2）上下文管理：100 万 token 上下文窗口加服务器端压缩，让复杂 RAG 架构变得不再必要；3）代码执行：托管沙盒允许模型在一次 API 调用中完成编写-运行-修复的完整闭环；4）计算机使用：原生 1440p 屏幕理解让 UI 自动化无需手动坐标计算。

对开发者最具价值的建议是：为弥补模型不可靠性而编写的代码"半衰期只有数月"——随着模型能力提升，这些努力很快过时。将开发重心转向"连接模型与你的世界"的代码——专有数据、自定义工具、特定领域上下文——才能创造复利价值。

Asana 详解如何利用 Claude Managed Agents 和 Workgraph 构建「多人协作」AI 队友

来源： BestBlogs.dev | 评分：92 | 发布时间：2026年5月8日 18:50 GMT

核心观点： Asana 在 Code with Claude 大会上展示了其"智能体企业"愿景——让 AI Agent 作为完全整合的团队成员，在人工监督下通过 Asana 17年积累的 Workgraph 上下文执行复杂协作任务。

深度摘要： Asana 正在重新定义企业 AI 的使用范式：从"单人辅助"升级为"多人协作"。其核心架构基于两个组件：Asana 的 Workgraph（17年积累的组织目标-项目-历史上下文）和 Claude 的 Managed Agents 平台。

技术层面，Asana 的多个 Agent 分工明确：主 Agent 负责任务分解和委派，子 Agent 分别在各自负责的领域工作，结果汇总后再由主 Agent 整合输出。整个过程与 Asana 的任务管理 API 深度耦合——每个 Agent 的工作成果直接写入 Asana 项目列表，人工可实时审核和干预。

这一架构解决了企业级 Agent 的三大难题：上下文不足（Workgraph 提供组织级记忆）、任务可审计性（所有 Agent 操作均有 Asana 日志）、人工监督（保留人工审批节点）。Asana 预计这一系统可将复杂跨团队项目的管理效率提升 40% 以上。

AI 编码 Agent 时代降临：从 GPT-5.5 到 Claude Opus 4.7 的能力跨越

来源： BestBlogs.dev | 评分：90 | 发布时间：2026年5月7日

核心观点： 2026年5月的模型军备竞赛正在重新定义 AI 编码的边界——GPT-5.5 在 AIME 2025 数学测试中从 65.4 跃升至 81.2，Claude Opus 4.7 已在代码漏洞发现领域建立统治地位，OpenAI 和 Anthropic 同时瞄准网络安全垂直场景。

深度摘要： 两条技术路线的对比引人注目。OpenAI 的 GPT-5.5（2026年4月底发布）侧重推理能力的全面提升：AIME 数学测试 81.2 分（+24%），MMMU-Pro 多模态推理 76 分（+10%）。更重要的是，其上下文管理能力大幅增强——可以回溯历史对话、文件和 Gmail 内容，给出个性化答案，同时全模型上线"记忆来源"透明度功能。

Anthropic 的 Claude Opus 4.7 则在安全场景建立差异化优势：在代码漏洞发现和修复任务中，Opus 4.7 的准确率比 GPT-5.5 Thinking 高出 15% 以上。Anthropic 还发布了 Claude Security（基于 Opus 4.7），面向企业级代码安全扫描。

两家公司的同步动作是推出网络安全专用模型——OpenAI 发布 GPT-5.5-Cyber（5月7日），Anthropic 发布 Claude Mythos Preview（4月），标志大厂正式将安全Agent 作为独立产品线运营。
